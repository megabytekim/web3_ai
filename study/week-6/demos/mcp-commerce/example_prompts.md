# MCP Commerce 테스트 프롬프트

Claude Desktop에서 MCP 서버 연결 후 테스트할 수 있는 프롬프트 모음입니다.

---

## PayPal MCP 테스트

### 거래 조회

```
내 PayPal 계정의 최근 7일간 거래 내역을 보여줘.
```

```
거래 ID가 "ABC123"인 거래의 상세 정보를 조회해줘.
```

### 청구서 생성

```
홍길동 (hong@example.com)에게 다음 내용의 청구서를 만들어줘:
- 컨설팅 서비스: $500
- 세금 8% 적용
- 10일 후 만료
```

```
청구서 목록을 보여주고, 미결제 청구서가 있으면 알려줘.
```

### 주문 생성

```
다음 상품으로 PayPal 주문을 생성해줘:
- 상품명: "Web Development Service"
- 금액: $1,200
- 통화: USD
```

## Shopify MCP 테스트

### 상품 관리

```
내 Shopify 스토어의 전체 상품 목록을 보여줘.
```

```
재고가 10개 미만인 상품을 찾아줘.
```

```
"Summer Collection" 컬렉션에 있는 상품들을 보여줘.
```

### 주문 관리

```
오늘 들어온 주문을 보여줘.
```

```
주문 번호 #1234의 상세 정보를 조회해줘.
```

```
배송 대기 중인 주문 목록을 보여줘.
```

### 상품 수정

```
상품 ID "gid://shopify/Product/123456"의 가격을 $99.99로 변경해줘.
```

```
"Nike Air Max"라는 이름의 상품을 찾아서 재고를 50개로 업데이트해줘.
```

## Stripe MCP 테스트

### 고객 조회

```
내 Stripe 계정의 고객 목록을 보여줘.
```

```
이메일이 "customer@example.com"인 고객의 결제 이력을 조회해줘.
```

### 결제 조회

```
최근 결제 목록을 보여줘.
```

```
환불된 결제 내역을 찾아줘.
```

---

## 복합 시나리오

### 다중 플랫폼 조회

```
Shopify에서 "운동화" 관련 상품을 찾고,
PayPal로 해당 상품의 청구서를 만들 수 있게 정보를 정리해줘.
```

### 재고 알림

```
Shopify 스토어에서 재고가 부족한 상품을 찾아서
재입고 주문을 위한 PayPal 청구서 초안을 만들어줘.
```

---

## 주의사항

1. **Sandbox 모드 사용**: 실제 결제가 발생하지 않도록 Sandbox 환경에서 테스트
2. **API 키 보안**: 설정 파일의 API 키를 Git에 커밋하지 않도록 주의
3. **Rate Limit**: 연속 호출 시 API Rate Limit에 주의

---

## 연결 확인 방법

Claude Desktop에서 MCP 서버가 정상 연결되면:
- 설정 → MCP 섹션에서 각 서버 옆에 **녹색 원** 표시
- "PayPal 계정 정보를 알려줘" 같은 간단한 프롬프트로 테스트
